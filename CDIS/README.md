## 🎯 About the Course

This repository contains the practical exercises, skill programs, project work and additional learning resources completed as part of the **Cloud Infrastructure and Services (CDIS)** course.

The coursework focuses on understanding cloud computing concepts and gaining hands-on experience with Amazon Web Services (AWS), cloud infrastructure management, networking, storage, security, monitoring and automation.

## 🛠️ Technologies and Services

- **Cloud Platform:** Amazon Web Services (AWS)
- **Compute:** Amazon EC2, AWS Lambda
- **Storage:** Amazon S3, Amazon EBS
- **Database:** Amazon RDS, Amazon DynamoDB
- **Networking:** VPC, Subnets, NAT Gateway, Security Groups, Network ACLs
- **Identity and Security:** AWS IAM, MFA
- **Messaging:** Amazon SQS
- **Monitoring:** Amazon CloudWatch
- **Development Tools:** AWS CLI, Docker, Git and GitHub

## 📚 Learning Areas

1. Cloud computing fundamentals and AWS account management.
2. Identity and access management.
3. Virtual machines and cloud computing resources.
4. Object and block storage services.
5. Cloud networking and infrastructure.
6. Serverless computing and message queues.
7. Managed databases and data recovery.
8. Monitoring, logging and alarms.
9. Cloud automation and deployment.
