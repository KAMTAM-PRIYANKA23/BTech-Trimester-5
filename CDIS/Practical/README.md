\## 📖 Overview



This directory contains the practical exercise materials and execution records for \*\*Cloud Infrastructure and Services (25CS2206E)\*\*.



It serves as a centralized location for practical manuals, experiment documentation, screenshots, command outputs and observations.



\## 🎯 Objectives



\- Understand the practical implementation of cloud computing concepts.

\- Gain experience in configuring and managing cloud resources.

\- Execute practical exercises using AWS services and related tools.

\- Record observations and verify experimental results.

\- Develop troubleshooting and cloud infrastructure management skills.



\## 🧰 Tools and Technologies



\- Amazon Web Services (AWS)

\- AWS Management Console

\- AWS CLI

\- Amazon EC2

\- Amazon S3

\- AWS IAM

\- Amazon VPC

\- CloudWatch

\- Linux / Ubuntu

\- Visual Studio Code

\- Git and GitHub
