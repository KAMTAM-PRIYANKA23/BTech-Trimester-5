\## 📖 Overview



This directory is dedicated to additional online learning resources, Massive Open Online Courses (MOOCs), course completion records and certifications related to Cloud Infrastructure and Services.



It provides a centralized space to maintain supplementary learning beyond the prescribed practical and skill programs.



\## 🎯 Objectives



\- Explore cloud computing topics through additional online courses.

\- Strengthen knowledge of AWS and cloud technologies.

\- Learn industry-relevant tools and practices.

\- Maintain course completion records and certificates.

\- Support continuous technical learning and skill development.



\## 📚 Learning Areas



\- Cloud Computing Fundamentals

\- Amazon Web Services (AWS)

\- Cloud Architecture and Infrastructure

\- Cloud Security and Networking

\- DevOps and Cloud Automation

\- Cloud Monitoring and Management
