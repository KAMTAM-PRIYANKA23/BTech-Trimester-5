## 📖 About the Course

Computer Networks and Network Programming focuses on understanding how data travels across networks and how communication protocols operate, from physical transmission to application-level communication.

The course covers network architecture, socket programming, TCP/IP, routing, switching, network security, automation and performance measurement through practical, hands-on learning.

It follows an **INSIDE-OUT approach**, emphasizing three major learning tracks:

- **SETU-LINK:** Designing and operating a programmable campus internetwork.
- **SETU-STACK:** Implementing a network protocol stack in C.
- **SETU-EDGE:** Engineering predictable network performance under network contention.

## 🎯 Course Outcomes

| CO | Learning Outcome |
|---|---|
| CO1 | Analyze network performance through measurements, packet captures, latency, throughput and queueing. |
| CO2 | Implement transport and application-layer mechanisms using C, sockets, TCP and HTTP. |
| CO3 | Design and implement IP addressing, routing, DHCP, NAT and campus internetworks. |
| CO4 | Analyze Ethernet, switching, VLANs, wireless communication and physical-layer performance. |
| CO5 | Troubleshoot and operate networks using security policies, monitoring and automation. |
| CO6 | Engineer predictable latency, jitter and QoS for real-time network traffic. |

## 🛠️ Technologies and Tools

The course introduces industry-relevant networking and automation technologies.

- **Programming:** C, Python
- **Network Analysis:** Wireshark, tcpdump, iperf3
- **Network Simulation and Switching:** Linux networking, Open vSwitch
- **Routing:** FRRouting
- **Network Services:** Kea DHCP, BIND9 DNS
- **Automation:** Ansible
- **Protocols:** TCP, UDP, HTTP, DNS, TLS, IPv4, IPv6
