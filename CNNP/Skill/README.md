## 📖 Overview

This section contains the hands-on Skill experiments performed as part of the Computer Networks and Network Programming course at KL University.

The experiments focus on understanding network behavior through practical implementation, packet analysis, performance measurement, troubleshooting and experimentation.

A total of **24 Skill sessions** are organized across six Course Outcomes (CO1–CO6).

## 🎯 Skill Objectives

- Understand network encapsulation and packet transmission.
- Analyze network performance using packet captures and measurements.
- Implement socket-based communication and TCP mechanisms.
- Explore IP addressing, routing and network configuration.
- Configure and troubleshoot switching and wireless networks.
- Apply network security, monitoring and automation techniques.
- Evaluate latency, jitter and Quality of Service (QoS).
