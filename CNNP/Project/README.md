## 📖 Overview

This directory is reserved for the course project undertaken as part of Computer Networks and Network Programming at KL University.

The project will focus on applying networking concepts through practical implementation, experimentation, performance evaluation and technical documentation.

## 🎯 Project Domains

The course provides three major project directions:

| Track | Focus Area |
|---|---|
| SETU-LINK | Programmable campus internetwork design and implementation |
| SETU-STACK | Network protocol stack implementation in C |
| SETU-EDGE | Predictable network performance under contention |

## 🔍 Expected Learning Areas

Depending on the selected project, implementation may involve:

- TCP/IP and socket programming
- Network protocols and communication
- Routing and switching
- Network performance measurement
- Network security and troubleshooting
- Network automation
- Latency, throughput and QoS analysis

## 🛠️ Technologies

Potential technologies include:

- C and Python
- Linux networking utilities
- Wireshark and tcpdump
- FRRouting and Open vSwitch
- Kea DHCP and BIND9
- Ansible

The final technology stack will depend on the selected project.
