## 📌 About This Repository

This repository serves as a structured record of coursework, hands-on skill development, technical experiments, and project implementations completed as part of the **Generative AI & AI Platform Engineering** course.

It focuses on exploring modern Generative AI technologies and developing practical knowledge of Large Language Models, AI APIs, prompt engineering, semantic search, information retrieval, and AI-powered applications.

## 📂 Repository Structure

| Directory | Description |
|:--|:--|
| [`Skill/`](./Skill/) | Practical skill exercises, technical experiments, execution records, and observations. |
| [`Project/`](./Project/) | Course projects, source code, implementation details, and technical documentation. |

## 🧠 Areas of Learning

- **Large Language Models:** Understanding LLMs, their capabilities, and applications.
- **Generative AI:** Exploring AI-powered content generation and intelligent applications.
- **Prompt Engineering:** Designing effective prompts and evaluating model responses.
- **LLM Integration:** Connecting applications with external AI models through APIs and SDKs.
- **Semantic Search:** Working with embeddings and meaning-based retrieval.
- **Information Retrieval:** Exploring keyword-based, dense, and hybrid retrieval techniques.
- **AI Platforms:** Understanding tools and technologies used to build AI applications.

- Develop practical skills in Generative AI application development.
